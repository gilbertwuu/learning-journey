# Third-party notices

The learning workflow is packaged independently of Compound Engineering. Its multi-skill distribution inspired this repository structure; no Compound Engineering source code is included.

The Plan board bundles the runtime and authoring references of [Archify](https://github.com/tt-a1i/archify), version 3.0.1, under `skills/plan/vendor/archify/`. Its MIT license is retained there, along with its third-party notices and embedded font license. The learning adapter changes only a private output copy when rendering. The bundled upstream files are otherwise unchanged. Automatic upstream update checks are disabled by our wrapper; updates are managed with plugin releases.

Archify's own code is MIT. Included fonts and optional brand data retain their separate terms; see [upstream notices](skills/plan/vendor/archify/THIRD_PARTY_NOTICES.md). The learning board suppresses node brand icons.
