# 公开参考样例

本插件使用虚构的 Python 学习案例，位于 `../../../examples/python-basics/`。它不是任何人的真实学习记录，也不是通用课程。`candidate.json` 展示节点关系，`notes.json` 展示学习证据格式。

继承的呈现约定：按阶段横向分区；蓝色为需要学习、灰色为已有相关认识；所有节点可点击查看证据；深浅主题、聚焦、返回全图与连线动画；节点标题居中；详情弹窗正文13px、400字重，小标题12px、500字重；图下不重复铺设说明卡片。

新主题必须重写节点、关系和证据。示例中的模拟起点不能作为新用户的诊断结果。

运行方式见仓库 README。实际生成的 HTML 和校验文件放在用户工作目录；不要写进已安装插件。
